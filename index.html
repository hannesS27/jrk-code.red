CODE RED

SYSTEMAUSFALL IN DER LEITSTELLE

⚡ ALARMSTUFE ROT

Ein unbekannter Computervirus hat heute um 03:47 Uhr alle digitalen Systeme der DRK-Rettungsleitstelle lahmgelegt. Fahrzeugdisposition, Alarmierungssoftware, GPS-Tracking – alles ausgefallen.

Gleichzeitig meldet die Feuerwehr einen sich schnell ausbreitenden Großbrand am Stadtrand. Ohne funktionsfähige Leitstelle droht eine Katastrophe.

📋 DIE MISSION

Der pensionierte Rettungssanitäter Hans Kemper hat in seiner Dienstzeit ein analoges Notfall-Protokoll entwickelt – für genau diesen Fall.

Er hat es in verschlüsselter Form hinterlassen. Ihr müsst es entschlüsseln, das System manuell neu starten und die Leitstelle wieder in Betrieb nehmen.

Ihr habt 60 Minuten. Dann eskaliert der Brand unkontrollierbar.

Verschiebung: +7 Stellen (jeder Buchstabe = 7 Positionen zurück im Alphabet)

// VERSCHLÜSSELTE BOTSCHAFT //

ILÄZLYLUN

↑ Cäsar +7 | Entschlüsselt ergibt das Lösungswort

Hilfe – Cäsar-Prinzip:
A=1, B=2 … Z=26. Verschiebung +7 bedeutet:
Buchstabe im Code → 7 zurückzählen im Alphabet
I(9)−7=B, L(12)−7=E, Ä→Ü...
Hinweis: Umlaute: Ä=Ae, Ö=Oe, Ü=Ue

LEVEL 2 – BESTANDSPRÜFUNG
// SYSTEM-DIAGNOSE //

Material-Inventur: Notfallkoffer

Gut! Das erste Protokoll ist entschlüsselt. Nun verlangt das System eine Bestandsprüfung des Erste-Hilfe-Materials. Hans Kempers Protokoll sagt: "Nur wer seinen Ausrüstungsstand kennt, kann im Notfall helfen."

Im Raum sind Erste-Hilfe-Gegenstände versteckt. Sucht und zählt sie!

// SUCHAUFTRAG //

Was ist zu finden?

  • Dreiecktücher – überall im Raum verteilt. Wie viele findet ihr?
  • Verbandspäckchen – klein, weiß, mit rotem Kreuz. Zählen!
  • Einweghandschuhe – einzelne Handschuhe zählen!

    • Der 4-stellige Zugangscode lautet: Dreiecktücher × Verbandspäckchen + Handschuhe

    Beispiel: 3 Tücher, 4 Päckchen, 2 Handschuhe → Code: 1402 (3×4=12, +02 = 1202)

    ⚠ Für dieses Spiel ist die Lösung vorher vom Spielleiter festgelegt!
